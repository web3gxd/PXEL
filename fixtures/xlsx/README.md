# Synthetic XLSX fixtures

`minimal_scalars.xlsx` is generated by `python fixtures/xlsx/generate_minimal.py`
using only Python's standard ZIP library. It contains two sheets, one shared
string with an XML entity, one inline string with a numeric character reference,
a finite number, a boolean and a formula with an intentionally wrong cached
value. No human data or spreadsheet framework is involved.

Expected normalized values: Budget!A1 = `hello & world`, B1 = `0`, C1 =
`TRUE`, D1 = formula source `A1+B1`; Plan!Z4 = `world!`. The formula cache
`999` must be ignored. This fixture has not been verified in Microsoft Excel;
it proves parser behavior only, not Excel compatibility.

`single_sheet_scalars.xlsx` is generated by the same script from the Budget
sheet. It exercises the bounded local document import; the two-sheet fixture
must be rejected by that profile without publishing a partial document.

`single_sheet_merge.xlsx` adds a merge region. The scalar import reports this
as `WorksheetMetadata` and rejects it by default. The local operator may use
`--allow-loss` to import only the supported cells after seeing that warning.
