# PXEL

Self-hosted collaborative spreadsheets for teams and local networks. A Rust
engine and PostgreSQL journal power a React/Canvas interface with live editing,
formulas, version history, sharing, and bounded CSV/XLSX import profiles.

**Pre-release.** Local Windows verification is recorded in [RUNBOOK.md](RUNBOOK.md).
Linux, production hosting and accessibility acceptance remain explicit
[deployment gates](docs/self-hosting.md#deployment-gates). This repository is
source software, not a production readiness certification.

## Self-hosting

The first launch guides the operator through creating a master account using a
private server-side bootstrap code. The master creates other accounts and has
full access to every book in the instance. New users change their temporary
password before accessing books. There is no public registration.

Use the [self-hosting guide](docs/self-hosting.md) for builds, HTTPS, configuration,
first-run setup and backup requirements. Development mode below uses separate
test identities and must stay on loopback.

## Development

Use Rust **1.98.1**, Node **24.18.0** (24.x), pnpm **12.6.0**, just **1.58.0**
and PostgreSQL **18.6**. Tool versions are pinned; see
[development notes](docs/development.md) for additional verification tools.

```sh
pnpm install --frozen-lockfile
just infra-up
just dev
```

Open <http://localhost:5173>. `infra-up` provisions an isolated development
PostgreSQL and credentials under ignored `.local/`. Native PostgreSQL is also
supported with `PXEL_PG_BIN` and `just infra-native`. Do not reuse a development
database as an existing self-hosted installation; initial setup refuses books
already present in a database.

```sh
just check
just sqlx-check
just smoke
just audit
pnpm repository:check
```

Database tests require an isolated `DATABASE_URL`. Never print it. SQLx metadata
is checked in for offline builds. Browser WASM is generated by `scripts/wasm.mjs`.
Actual XLSX parsing additionally needs the pinned
[WASI runtime and resource limits](docs/setup/xlsx-wasi.md); upload fails closed
without them.

## Project

- [Architecture](docs/architecture.md), [ADRs](docs/adr), [roadmap](docs/roadmap.md)
- [Development and extended verification](docs/development.md)
- [Contributing](CONTRIBUTING.md), [security reports](SECURITY.md)

PostgreSQL is authoritative. The server acknowledges changes after a durable
commit. Browser formula previews remain separate from confirmed calculations.
The default blob store is local filesystem; no extra storage service is needed.
Encryption at rest protects stored content, while the running server and master
account can read it. It is not end-to-end encryption.
