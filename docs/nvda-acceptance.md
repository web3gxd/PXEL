# Ручная приёмка дополнений PXEL с NVDA

Статус: не выполнена. Автоматические проверки фокуса, клавиатуры и ARIA
прошли в Chromium при DPR1/DPR2; они не подтверждают реальное озвучивание.
Результаты общего прогона находятся в [RUNBOOK](../RUNBOOK.md).

## Подготовка

Запустите локальный стенд по README (`just dev`) с изолированной PostgreSQL
и тестовыми данными. Используйте NVDA и Chromium на Windows. Запишите версии
Windows, браузера и NVDA, язык речи, масштаб браузера и дату. Проверяйте только
искусственные значения; PIN, пароль и реальные персональные данные в отчёт
не включайте. При просмотре Speech Viewer также не сохраняйте секреты.

Каждый сценарий выполните клавиатурой. Для диалогов проверьте объявление
названия и описания, начальный фокус, порядок Tab/Shift+Tab, ограничение фокуса
диалогом, Escape и возвращение фокуса к вызвавшей кнопке. Запишите фактически
услышанное, а не только ожидаемую ARIA-разметку. Повторите основные переходы
при ширинах 390/1440 и в светлой/тёмной теме; DPR1/DPR2 проверены автоматикой.

| Защищённые ссылки     | Выбрать роль, каждый из четырёх сроков и режим данных                           | Названия и выбранные значения; предупреждение о правах, отдельной передаче секретов и невозможности отозвать копии |
| Бессрочная ссылка     | Выбрать бессрочный срок, подтвердить и отменить                                 | Обязательное подтверждение и его состояние; отказ создания без подтверждения                                       |
| Гостевой вход         | Перейти по тестовой ссылке, заполнить PIN клавиатурой                           | Названия полей и состояния ошибок; секрет не попадает в отчёт                                                      |

| Профайлер             | Открыть отчёт и выбрать цепочку                                                 | Версия, устаревание/усечение, текстовое представление зависимостей вместо обязательного чтения графика             |

| Политики              | Запретить копирование/экспорт и попытаться выполнить их                         | Понятное сообщение об отказе; Cut сохраняет исходный текст                                                         |
| `.pxel`               | Экспортировать с тестовым паролем, импортировать, проверить неправильный пароль | Метки пароля, состав файла, отметка обезличивания и ошибка без частично созданной книги                            |

## Отчёт

Для каждой строки запишите «пройдено» или «дефект», фактическую речь, шаги,
ожидаемый результат и настройки среды. Не оставляйте пропущенный сценарий
помеченным как пройденный. Отдельно перечислите пропуски и причины.
Результат добавляется в RUNBOOK только после реального прохода человеком;
этот документ сам по себе не закрывает NVDA gate.
