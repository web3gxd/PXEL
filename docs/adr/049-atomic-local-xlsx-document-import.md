# ADR-049: атомарная публикация локального XLSX через существующие события

Status: accepted for the next bounded phase-6 slice (2026-09-29).

## Контекст и изменение решения

RUNBOOK после ADR-048 предполагал отдельное versioned genesis-событие импорта.
Это оказалось избыточным для текущей одно-листовой domain model: существующие
`CreateWorkbook`, `SetCellValues` и `SetCellFormula` полностью выражают
поддержанный scalar import. Публикация последовательными отдельными commit
показала бы пользователю частично загруженную книгу. Поэтому все события
предварительно применяются к candidate projection и записываются в одной
PostgreSQL transaction вместе с `documents.head_version` и owner permission.
До commit документ не виден; при сбое любого insert транзакция откатывается.

## Контракт среза

Локальная команда `xlsx-import <path> <workspace_id> <actor_id>` компилируется
только с `dev-auth` и требует `PXEL_DEV_AUTH=1` с loopback-конфигурацией.
Actor/workspace IDs разрешены только как операторский локальный инструмент;
публичный HTTP/WS import не принимает IDs от клиента. Авторизация членства
workspace повторяется в той же транзакции. Недоверенный файл разбирает
существующий дочерний worker; parent повторно валидирует normalized IR.

Профиль: один лист, до 1000 заполненных ячеек, числа/текст/boolean/поддержанные
формулы, оси до 100000 строк и 1000 колонок. Формулы парсятся и связываются
сервером до транзакции; invalid references отклоняются. Операции получают
монотонные версии 1..N и отдельные UUIDv7. Журнал ограничен 32 MiB суммарно;
обычный лимит 4 MiB на событие сохраняется. Повтор точно тех же prepared
events для того же document ID сравнивается по ID и canonical event hash;
новая CLI-инвокация создаёт новый document ID и пока не является retry
прежнего намерения. Import audit/job records и compatibility report ещё нет.

## Последствия

Persisted schema не меняется, старые события не мигрируются. Двухлистовой
fixture пока отвергается целиком. Для нескольких листов понадобится расширить
domain/snapshot model и затем отдельный versioned event; прежнее предположение
остаётся применимым к этому будущему случаю. До появления OS-level sandbox,
malware scan и полного отчёта совместимости команда остаётся локальной и
загрузка файлов через веб-интерфейс не открывается.
