# ADR-039: S3 adapter для snapshots

Статус: принят для локального среза фазы 5, 2026-09-29. Совместимость с
Garage и российским S3 остаётся gate.

## Контекст

LocalFilesystemBlobStore уже выполняет контракт неизменяемых объектов, но
снимки должны работать с S3-совместимым хранилищем в production. У платформ
могут различаться детали условной записи и checksum headers, поэтому одного
компилируемого SDK-клиента недостаточно.

## Решение

`spreadsheet-storage/s3` включает закреплённые `aws-sdk-s3 1.150.0` и
`aws-config 1.12.0` с современным `default-https-client` на rustls 0.23.
Отдельный SDK feature `rustls` не используется: он притягивал старую TLS-ветку
с опубликованными advisory. Серверный feature `s3` выбирает адаптер при
наличии `PXEL_S3_ENDPOINT`, `PXEL_S3_BUCKET`, `PXEL_S3_REGION`; иначе остаётся
локальный adapter. Credentials берутся из стандартной SDK chain, не из
document protocol и не пишутся в журнал/логи. Endpoint требует HTTPS вне
loopback; S3 bucket и region валидируются. Запросы используют path-style,
подписываются SDK и имеют ограниченное время.

`put` сначала ограниченно считывает source во временный файл и сверяет SHA-256.
`PutObject` с `If-None-Match: *` не перезаписывает существующий ключ. Ответ 412
проверяется полноценным `get`: одинаковый body — идемпотентный retry, другой
body — `KeyConflict`. 409 повторяется ограниченное число раз. `get` и `head`
полностью проверяют скачанный объект и его `pxel-sha256` metadata перед
передачей результата; для этого они используют ограниченный файл, а не буфер
всей книги в памяти. `delete` идемпотентен. Адаптер не записывает детали ошибок
SDK в обычные production-логи, чтобы не вывести содержимое или реквизиты запроса.
В production временный каталог ОС для этих файлов должен принадлежать только
service account и находиться в выбранном контуре хранения данных.

## Проверка и границы

S3-контракт на Moto 5.2.3 выполняет реальный HTTP S3 протокол: потоковая
запись/чтение, checksum, 404, повтор, конфликт, одновременные условные
записи, ограничения размера и delete. Серверный hard-restart integration test
с `PXEL_SNAPSHOT_INTERVAL=1` создал ACTIVE снимки через S3, а объект и metadata
проверены отдельным HEAD. Это не доказывает совместимость Garage 2.4.0,
российского S3, durability сервиса или power-loss. Их контракты запускаются
позже с тем же `just s3-contract` на соответствующем endpoint.

Локальный Moto хранится только под игнорируемым `.local`; не входит в runtime
или Compose. SDK добавляет заметное время сборки и размер dependency graph;
S3 feature остаётся опциональным для локальной разработки.
