# ADR-127: стабильный маскированный вид при обновлении

Дата: 2026-10-06. Статус: принято.

При несовпадении версии локальной маски с подтверждённой книгой интерфейс
показывает предыдущую безопасную маскированную проекцию по стабильным ID.
Новые ячейки до завершения анализа пусты. Оригинальные актуальные значения
не подставляются. Плашки остаются, но раскрытие оригиналов запрещено, пока
маска устарела. Существующие блокировки копирования/заполнения и предупреждение
об обновлении остаются. После анализа проекция заменяется целиком.

Подтверждённый axisSizeWrite не меняет распознаваемое содержимое: актуальная
маска переносится на следующую версию в обоих путях канонических событий.
Уже устаревшая маска никогда не повышается таким способом. События изменения
содержимого продолжают требовать анализа. Сервер и зависимости не меняются.
