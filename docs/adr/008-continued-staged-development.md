# ADR-008: продолжение стадий после локальной проверки foundation

Дата: 2026-09-28. Статус: принято по новому поручению пользователя.

Предыдущее решение останавливало работу после skeleton до следующего разрешения.
После отчета о прошедших локальных тестах и отсутствии Linux runtime пользователь
явно поручил «идем дальше все остальные стейджи». Это разрешает последовательную
реализацию фаз 1–6 с сохранением исходных инвариантов и обязательных исправлений.

Linux/Compose/remote CI не становятся зелеными по этому разрешению. Сохраняем
PH0-LINUX-GATE как открытый пункт перед утверждением Linux tested baseline и
production deployment. WSL status повторно сообщил, что WSL не установлен;
Docker Engine отсутствует. Не изменяем системные службы или внешние VDS ради gate.

Каждый срез сопровождается кодом, реальными тестами и записью RUNBOOK. Формулы и
collaboration используют согласованные исправления, а новые существенные решения
получают ADR и fixtures. Не требуется повторное разрешение на уже порученную работу.
Нет миграции данных от этого решения; изменения persisted schemas остаются append-only.

Первая цель: typed sparse workbook → create document → SetCellValue/ClearCell →
candidate validation/hash → PostgreSQL CAS commit → replay после reload/restart.
Риски: потеря ACK, два writer, отзыв прав, повтор operation_id с другим payload,
server auth identity после restart. Они проверяются до объявления среза завершенным.

Параллельная отдельная задача: убрать header brand и подготовить 10 SVG logo concepts
на основе текущего grid mark, без автоматической замены выбранным новым логотипом.
